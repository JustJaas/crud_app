## Getting Started

Aplicación desarrollada con Flutter

## Qué hace la app

- Lista las tareas guardadas localmente.
- Crea tareas con validación de formulario, título obligatorio, mínimo 3 caracteres.
- Muestra el detalle de una tarea.
- Edita tareas existentes.
- Elimina tareas.
- Marca tareas como completadas con un checkbox.
- Mensaje cuando no hay tareas.

## Probar

```bash
flutter pub get
flutter run
```
