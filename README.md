# Gestor de Tareas



## Getting Started

Aplicación desarrollada con Flutter

## Qué hace la app

- Lista las tareas guardadas localmente (persisten aunque se cierre la app).
- Crea tareas con validación de formulario (título obligatorio, mínimo 3 caracteres).
- Muestra el detalle de una tarea.
- Edita tareas existentes (el mismo formulario sirve para crear y editar).
- Elimina tareas (deslizando la fila o desde el detalle).
- Marca tareas como completadas con un checkbox.
- Estado vacío cuando no hay tareas.

## Probar

```bash
flutter pub get
flutter run
```
